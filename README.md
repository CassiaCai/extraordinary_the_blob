# How extraordinary was the 'Blob' marine heatwave?

This repository contains the analysis code associated with our *Geophysical Research Letters* paper submission.

## Overview

The **Blob** was a persistent marine heatwave (MHW) in the Northeast Pacific, with major ecological and economic
impacts. This study compares the CESM2-FOSI representation of the Blob against
"Blob-analogs" from a 100-member large ensemble of coupled climate model
simulations (CESM2-LENS) to assess whether the event's physical characteristics and
drivers were extraordinary relative to internal climate variability.

We evaluate:
- Spatiotemporal characteristics (extent, duration, intensity, mixed layer depth)
- Vertical (subsurface) temperature structure
- Heat budget evolution and phase decomposition
- Large-scale climate context (PDO, ENSO)
- Sensitivity of Blob-analog detection to SSTa definition and forced-signal (Time of
  Emergence) analysis

## Repository structure

All analysis notebooks live in `notebooks/`. 
1. `identifyingmhwsinfosi.ipynb`: MHW identification/tracking in CESM2-FOSI (Ocetrac).
2. `computeFOSIheatbudget.ipynb` / `computeLENS2heatbudget.ipynb`: Heat budget
   construction for FOSI and LENS.
3. `heat_budget_analysis.ipynb`: Peak-tendency classification, warming/cooling-peak
   composites, canonical-footprint heat budget results.
4. `blob_fosi_subsurface_heatbudg_mld.ipynb` / `vertical_temperature_structure.ipynb`: 
   Subsurface temperature structure, depth-of-reach, canonical vs. time-varying
   footprint comparison.
5. `extractingspatempmetrics.ipynb`: Physical characteristics (extent, duration,
   intensity, MLD) for the Blob-analog population.
6. `nino_pdo.ipynb` / `section_3_2_climate_context.ipynb`: PDO/Niño3.4 climate
   context and correlations with event severity.
7. `snr_time_of_emergence.ipynb`: Forced-signal detection (SNR/Time of Emergence)
   across four SSTa definitions.
8. `Blob_in_FOSI_w_prevevent.ipynb`: FOSI Blob narrative, including the precursor
   MHW discussion.
9. `figure1.ipynb`, `figure2.ipynb`, `supfigS1.ipynb`: Figure generation.
10. `ocetrac_on_lens_SSTadef.ipynb`: Ocetrac on 100 LENS members using varying Ocetrac parameters and SSTa definitions
`analysis_functions.py` and `cesm2_lens_utils.py` contain shared utility functions
(detrending, anomaly calculation, regridding) used across the notebooks above.

## Data availability

The forced-ocean simulation (CESM2-FOSI) and fully coupled large ensemble
(CESM2-LENS) used in this study are available from:
- CESM2-LENS: https://www.cesm.ucar.edu/community-projects/lens2
- CESM2-FOSI: https://www.earthsystemgrid.org/dataset/ucar.cgd.cesm2.smyle.html

Intermediate processed data products (heat budget composites, subsurface profiles)
generated by these notebooks are not included in this repository due to size, but
can be regenerated by running the notebooks against the source data above.
