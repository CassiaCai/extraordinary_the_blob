# How extraordinary is the 'Blob' marine heatwave?
This repository contains the analysis code associated with our *Geophysical Research Letters* paper submission:

## Overview

The **Blob** was a persistent marine heatwave (MHW) in the Northeast Pacific from 2013–2015, with major ecological and economic impacts. This study compares the observed Blob against "Blob-analogs" extracted from a large ensemble of fully coupled climate model simulations to assess whether the event reflects typical variability or represents an extreme outlier.

We evaluate:
- Spatiotemporal characteristics
- Vertical structure
- Heat budget evolution

**Note:** The `scratch/` folder contains preliminary or messy code used during development. Final analysis scripts will be migrated to the root or organized into subdirectories (e.g., `src/`, `notebooks/`).
